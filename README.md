# Hotel

RESTful web-проект системы для управления отелем.

## Содержание
* **Структура проекта**
* **Стек технологий**

## Структура проекта

Проект реализован по многомодульной архитектуре Maven:

* **app** - основной модуль, содержит конфигурацию Spring Boot, Flyway-миграции и входную точку в приложение.
* **controller** - содержит REST-контроллеры для управления комнатами, гостями и услугами, а также глобальный обработчик исключений.
* **service** - содержит бизнес-логику системы, включая сервисы аутентификации, управления бронированием, DTO-классы и мапперы.
* **dao** - модуль доступа к данным, содержит реализации интерфейсов репозиториев с использованием Hibernate.
* **model** - ядро проекта, содержит доменные сущности, перечисления  и кастомные исключения.
* **logs** - директория, содержащая файлы логов работы приложения.
* **Dockerfile** - инструкции для сборки Docker-образа приложения.
* **docker-compose.yaml** - конфигурация для быстрого развертывания инфраструктуры.
